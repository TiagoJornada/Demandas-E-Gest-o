# Gestão UDI

Sistema desenvolvido em Streamlit para gerenciamento administrativo da Unidade de Diagnóstico por Imagem (UDI).

## Funcionalidades

- Registro de Demandas
- Controle de Férias
- Registro de Abonos
- Controle de Afastamentos

Os dados são armazenados em uma planilha do Google por meio do Google Apps Script.

## Tecnologias

- Python
- Streamlit
- Google Apps Script
- Google Sheets

## Como executar

Instale as dependências:

```bash
pip install -r requirements.txt
```

Execute a aplicação:

```bash
streamlit run gestao_udi.py
```
